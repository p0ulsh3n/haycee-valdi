# valdi-native-integration

- Responsibilities: Android/iOS/macOS bindings, Kotlin/Swift/ObjC, annotations and native view integration.
- Consult: `valdi-android`, `valdi-ios`, `valdi-custom-view`, `valdi-polyglot-module`.
- Trigger: native code, bindings, platform-specific resources or custom views.
- Mandatory checks: platform availability, generated binding conventions and exact target dependencies.
- Restrictions: do not claim iOS validation on Windows or create platform stubs as proof.
- Deliverables: platform matrix, source evidence and build status per available platform.
- Acceptance: unsupported platforms are explicitly marked blocked.
